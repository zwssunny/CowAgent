> 本リリースは [2.1.8 マルチ Agent 版](https://docs.cowagent.ai/ja/releases/v2.1.8) の最適化リリースであり、同版をベースにマルチ Agent の協調体験・モデル機能・チャネル連携について一連の機能最適化と問題修正を行いました。

## 🤝 マルチ Agent 体験の最適化

マルチ Agent チームの使用体験をさらに最適化しました：

- **マルチ Agent のセッション選択**：セッション内のマルチ Agent セレクターにリード Agent の識別を追加し、リード Agent とメンバーを明確に区別できるようにしました。あわせて単一 Agent の場合は表示を簡素化します。
- **協調の修正**：マルチ Agent のグループチャットで、リード以外の Agent からのタスク委譲が失敗する問題を修正し、Agent メンバーの識別を正しく行うようにしました。
- **メンバー Agent の画像レンダリング**：デフォルト以外の Agent が生成した画像成果物が Web 側とデスクトップクライアントで表示されない問題を修正しました。
- **グループチャットの入口**：デスクトップの「チーム」ページにグループチャットの入口を追加し、Agent チームからグループセッションを直接開始できるようにしました。

## 📡 チャネル連携の修正

コンソールのチャネル起動・停止の経路における重要な問題を修正し、チャネル連携をより安定させました：

- **デスクトップのチャネル連携修正**：デスクトップクライアントでチャネル連携を起動できない問題を修正しました。
- **チャネル停止の修正**：チャネル停止フローで `app_module` の探索が失われ、切断エラーを引き起こす問題を修正しました（#3141 で生じたリグレッション）。
- **QQ チャネルの再接続**：QQ チャネルが WebSocket 接続のサイレント切断後に再接続しない問題を修正し、自動的に再接続するようにしました。

## 🤖 モデル機能

- **モデルリストの設定**：モデルプロバイダーがモデルリストを設定できるようになり、モデル名・モデルタイプ・コンテキストウィンドウ・最大出力などを指定できます。Thanks @alanyz106 (#3146)

<img src="https://cdn.jsdelivr.net/gh/zhayujie/cowagent-assets@main/screenshots/en/model-catalog-config.png" alt="モデルリストの設定" width="800" />

- **複数のフォールバックモデルに対応**：メインモデルが失敗した場合、設定した順序付きのフォールバックチェーンを順に試行するようになり、従来の単一フォールバックモデルを置き換えました。Thanks @alanyz106 (#3125)

<img src="https://cdn.jsdelivr.net/gh/zhayujie/cowagent-assets@main/screenshots/en/model-fallback-chain.png" alt="複数のフォールバックモデル" width="800" />

- **フォールバック時の認証情報の修正**：フォールバック時のカスタム認証情報の解決を修正し、グローバル設定ではなく実際にルーティングされたプロバイダーに基づいて認証情報を解決するようにしました。Thanks @alanyz106 (#3142)
- **画像モデルの追加**：`gpt-image-2.5-flare` と `gpt-image-2.5-sunburst` を追加しました。Thanks @cowagent (#3140)

## 🛠 その他の最適化と修正

- **設定ファイルの許容**：`config.json` の UTF-8 BOM を許容し、ログイン前の 401 ポーリングを停止して、未ログイン時の無効なリクエストを回避しました。
- **画像生成の修正**：
  - 百度文心の `IMAGE_CREATE` が非対応時にクラッシュする問題を修正し、エラーメッセージを返すようにしました（Thanks @c020627 #3144）。
  - Midjourney の返信リトライ時に送信ロジックを正しく再帰呼び出ししない問題を修正しました（Thanks @c020627 #3151）。
- **音声の修正**：silk 音声のトランスコードを修正し、silk を独立した wav にデコードしてから mp3 に再エンコードすることで、ソースファイルの上書きを回避しました（Thanks @c020627 #3149）。
- **メディア URL の分類**：解決後の URL パスに基づいてメディアタイプを判定し、メディアリンクの分類誤りを修正しました（Thanks @c020627 #3150）。
- **百度翻訳**：百度翻訳がすべてのリトライに失敗した後に API エラーを報告しない問題を修正しました（Thanks @c020627 #3147）。
- **バックグラウンドコマンドの判定**：`run_in_background` を長時間実行のプロセスに限定し、タスクが早すぎるタイミングで完了と判定されるのを防ぎました。
- **ツール出力の切り詰め**：保持行が部分的に切り詰められた際に、バイト単位での切り詰め理由を正しく報告するようにしました（Thanks @c020627 #3137）。
- **Web モバイルレイアウト**：モバイルでのコンソール表示レイアウトを最適化しました。
- **デスクトップクライアント**：マルチ Agent チームのメニューが表示されない問題を修正しました。

## 📦 アップグレード方法

- **ソースデプロイ**：`cow update` でワンクリック更新するか、最新コードを取得して再起動します。詳しくは[アップグレードガイド](https://docs.cowagent.ai/ja/guide/upgrade)を参照してください。
- **デスクトップクライアント**：クライアント内で更新を確認してワンクリックで更新するか、[ダウンロードページ](https://cowagent.ai/download/)から最新版を入手できます。
