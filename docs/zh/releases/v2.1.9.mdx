> 本次为 [2.1.8 多 Agent 版本](https://docs.cowagent.ai/zh/releases/v2.1.8) 的优化版本，在该版本基础上对多 Agent 协作体验、模型能力与通道接入做了一系列功能优化和问题修复。

## 🤝 多 Agent 体验优化

围绕多 Agent 团队的使用体验进一步优化：

- **多 Agent 会话选择**：会话中的多 Agent 选择器新增主 Agent 标识，明确区分主 Agent 与成员，同时精简单 Agent 场景的视图。
- **任务协同修复**：修复多 Agent 群聊中非主 Agent 任务委派存在失败的问题，正确识别 Agent 成员身份。
- **成员 Agent 图片渲染**：修复非默认 Agent 生成的图片产物在 Web 端和桌面客户端无法渲染的问题。
- **群聊会话入口**：桌面端「团队」页新增群聊入口，可直接从 Agent 团队发起群聊会话。

<img src="https://cdn.link-ai.tech/doc/20260914122427.png" alt="模型列表配置" width="800" />

## 📡 通道接入修复

修复控制台通道启停链路上的关键问题，使通道接入更稳定：

- **桌面端通道接入修复**：修复桌面客户端中通道接入无法启动的问题。
- **通道停止问题修复**：修复通道停止流程中 `app_module` 查找丢失、导致断开异常的问题（由 #3141 引入的回归）。
- **QQ 通道重连**：修复 QQ 通道连接静默断开后不重连的问题，支持自动重连。

## 🤖 模型能力

- **模型列表配置**：模型厂商支持配置模型列表，可设置模型名、模型类型、上下文窗口、最大输出等信息。Thanks @alanyz106 (#3146)

<img src="https://cdn.link-ai.tech/doc/20260914112944.png" alt="模型列表配置" width="800" />

- **支持多兜底模型**：主模型失败时按配置的兜底模型依次尝试，替代原先单一兜底模型。Thanks @alanyz106 (#3125)

<img src="https://cdn.link-ai.tech/doc/20260914120209.png" alt="多兜底模型" width="800" />

- **回退凭据修复**：修复回退时自定义凭据的解析问题，改为按实际路由到的厂商解析凭据，而非全局配置。Thanks @alanyz106 (#3142)
- **新增图像模型**：接入 `gpt-image-2.5-flare` 与 `gpt-image-2.5-sunburst`。Thanks @cowagent (#3140)

## 🛠 其他优化与修复

- **配置文件容错**：兼容 `config.json` 的 UTF-8 BOM，并停止登录前的 401 轮询，避免未登录时的无效请求。
- **图像生成修复**：
  - 修复百度文心 `IMAGE_CREATE` 在不支持时直接崩溃的问题，改为返回错误提示（Thanks @c020627 #3144）。
  - 修复 Midjourney 回复重试时未正确递归调用发送逻辑的问题（Thanks @c020627 #3151）。
- **语音修复**：修复 silk 语音转码问题，先将 silk 解码为独立 wav 再重编码为 mp3，避免源文件被覆盖（Thanks @c020627 #3149）。
- **媒体 URL 分类**：按解析后的 URL 路径判断媒体类型，修复媒体链接分类错误的问题（Thanks @c020627 #3150）。
- **百度翻译**：修复百度翻译在全部重试失败后未上报 API 错误的问题（Thanks @c020627 #3147）。
- **后台命令判定**：将 `run_in_background` 限制为后台长时运行的进程，避免任务过早判定为完成。
- **工具输出截断**：当保留行被部分截断时，正确输出按字节截断的原因（Thanks @c020627 #3137）。
- **Web 移动端布局**：优化控制台在移动端的布局显示。
- **桌面客户端**：多智能体团队菜单无法显示问题修复。

## 📦 升级方式

- **源码部署**：执行 `cow update` 一键升级，或手动拉取代码后重启。详见 [更新升级文档](https://docs.cowagent.ai/zh/guide/upgrade)。
- **桌面客户端**：可在客户端内自动检查并一键更新，或前往 [下载页](https://cowagent.ai/zh/download/) 获取最新版本。
